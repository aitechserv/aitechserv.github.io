# AITechServ Website

Jekyll website for [aitechserv.ae](https://aitechserv.ae), hosted on GitHub Pages.

## Structure

- `_config.yml` — site settings (title, description, contact email)
- `index.html` — homepage
- `style.css` — styles
- `CNAME` — custom domain for GitHub Pages
- `404.html` — not-found page

## Editing

Edit `index.html` for content changes, `_config.yml` for site-wide settings. GitHub Pages rebuilds automatically on every commit.
